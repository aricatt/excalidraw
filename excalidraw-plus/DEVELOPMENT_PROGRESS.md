### 优先级 1: 核心编辑器功能

#### 1.2 缩略图生成 (计划中)
**预计时间**: 30分钟

**计划实现**:
1. 前端使用 Excalidraw 的 `exportToBlob` API 生成缩略图
2. 保存时将缩略图转为 base64 或上传到服务器
3. Dashboard 显示真实缩略图

**技术方案**:
```typescript
// 在 Editor.tsx 中
import { exportToBlob } from '@excalidraw/excalidraw';

const generateThumbnail = async () => {
  if (!excalidrawAPI) return null;
  
  const elements = excalidrawAPI.getSceneElements();
  const appState = excalidrawAPI.getAppState();
  
  const blob = await exportToBlob({
    elements,
    appState,
    files: null,
    mimeType: 'image/png',
    quality: 0.8,
  });
  
  // 转为 base64 或上传
  return blob;
};
```
