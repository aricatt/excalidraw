# 05-协作功能

## 📋 功能概述

协作功能是 Excalidraw Plus 的核心竞争力，提供实时多人协作编辑、权限管理、成员邀请、协作状态显示等功能，让团队能够高效地共同创作和编辑绘图。

## 🎯 核心功能

### 5.1 实时协作编辑
- **多人同时编辑**: 支持多个用户同时编辑同一绘图
- **实时同步**: 元素创建、修改、删除实时同步
- **冲突解决**: 智能处理编辑冲突和版本合并
- **光标显示**: 显示其他用户的光标位置和选择状态

### 5.2 成员管理
- **邀请成员**: 通过邮箱或邀请链接邀请新成员
- **角色权限**: Owner、Admin、Member、Viewer 四级权限
- **成员列表**: 显示所有协作成员及其在线状态
- **权限控制**: 细粒度的操作权限控制

### 5.3 协作状态显示
- **在线用户**: 实时显示正在协作的用户头像
- **用户光标**: 不同颜色标识不同用户的操作
- **选择状态**: 显示用户当前选中的元素
- **操作历史**: 记录用户的操作历史和时间线

### 5.4 邀请管理
- **邀请链接**: 生成带过期时间的邀请链接
- **邮箱邀请**: 直接发送邮箱邀请
- **待审核邀请**: 管理待处理的邀请请求
- **邀请撤销**: 撤销已发送的邀请

## 🔧 技术实现

### 5.5 数据模型
```typescript
interface Collaboration {
  id: string;
  drawingId: string;
  userId: string;
  permission: 'owner' | 'admin' | 'member' | 'viewer';
  joinedAt: Date;
  lastActiveAt: Date;
  invitedBy?: string;
}

interface CollaborationSession {
  id: string;
  userId: string;
  drawingId: string;
  socketId: string;
  cursor: { x: number; y: number };
  selection: string[]; // 选中的元素 ID
  isActive: boolean;
  connectedAt: Date;
  lastSeenAt: Date;
}

interface DrawingInvitation {
  id: string;
  drawingId: string;
  email: string;
  permission: 'admin' | 'member' | 'viewer';
  token: string;
  expiresAt: Date;
  invitedBy: string;
  status: 'pending' | 'accepted' | 'expired' | 'cancelled';
  createdAt: Date;
}

interface CollaborationEvent {
  id: string;
  drawingId: string;
  userId: string;
  eventType: 'join' | 'leave' | 'edit' | 'comment' | 'share';
  eventData: any;
  timestamp: Date;
}
```

### 5.6 WebSocket 事件
```typescript
// 协作相关 WebSocket 事件
interface CollaborationEvents {
  // 用户连接管理
  'user:join': { user: User; drawingId: string };
  'user:leave': { userId: string; drawingId: string };
  'user:cursor': { userId: string; x: number; y: number };
  'user:selection': { userId: string; elementIds: string[] };
  
  // 绘图协作
  'drawing:elements-update': { 
    elements: ExcalidrawElement[]; 
    userId: string; 
    timestamp: number 
  };
  'drawing:app-state-update': { 
    appState: Partial<AppState>; 
    userId: string 
  };
  
  // 权限管理
  'permission:updated': { 
    userId: string; 
    newPermission: string; 
    updatedBy: string 
  };
  'member:added': { user: User; permission: string; addedBy: string };
  'member:removed': { userId: string; removedBy: string };
}
```

### 5.7 API 端点
```typescript
// 协作管理
GET    /api/drawings/:id/collaborators     // 获取协作者列表
POST   /api/drawings/:id/invite            // 邀请协作者
PUT    /api/drawings/:id/collaborators/:userId // 更新协作者权限
DELETE /api/drawings/:id/collaborators/:userId // 移除协作者

// 邀请管理
GET    /api/drawings/:id/invitations       // 获取邀请列表
POST   /api/drawings/:id/invitations       // 创建邀请
DELETE /api/invitations/:id                // 取消邀请
POST   /api/invitations/:token/accept      // 接受邀请

// 实时协作
GET    /api/drawings/:id/sessions          // 获取活跃会话
POST   /api/drawings/:id/join              // 加入协作会话
POST   /api/drawings/:id/leave             // 离开协作会话

// 协作历史
GET    /api/drawings/:id/activity          // 获取协作活动历史
GET    /api/drawings/:id/versions          // 获取版本历史
POST   /api/drawings/:id/restore           // 恢复到指定版本
```

## 📱 用户界面

### 5.8 协作者显示
- **用户头像**: 右上角显示正在协作的用户头像
- **在线状态**: 绿色圆点表示在线状态
- **用户信息**: 悬停显示用户名和权限
- **最大显示**: 显示前 5 个用户，更多用户显示 "+N"

### 5.9 邀请界面
- **邀请按钮**: "Invite user" 和 "Create invite link"
- **邀请表单**: 邮箱输入、权限选择、过期时间设置
- **邀请链接**: 生成的链接和复制功能
- **待审核列表**: "Pending invitations" 显示待处理邀请

### 5.10 权限管理
- **成员列表**: 显示所有成员及其角色
- **权限下拉**: 快速修改成员权限
- **移除按钮**: 移除成员功能
- **权限说明**: 清晰的权限说明文档

## 🔄 冲突解决策略

### 5.14 操作时间戳
```typescript
interface ElementUpdate {
  elementId: string;

  data: ExcalidrawElement;
}
```

### 5.15 冲突解决规则
1. **最后写入获胜**: 基于时间戳的冲突解决
2. **元素锁定**: 正在编辑的元素临时锁定
3. **智能合并**: 非冲突属性自动合并
4. **用户提示**: 冲突发生时友好提示用户

## 🔄 实时同步机制

### 5.16 数据同步流程
1. **用户操作** → 本地立即更新
2. **发送事件** → WebSocket 发送到服务器
3. **服务器处理** → 验证权限和数据
4. **广播更新** → 推送给其他协作者
5. **客户端更新** → 其他用户界面更新

### 5.17 离线处理
- **离线缓存**: 本地存储未同步的操作
- **重连机制**: 网络恢复后自动重连
- **数据合并**: 重连后智能合并离线操作
- **冲突提示**: 合并冲突时提示用户选择
