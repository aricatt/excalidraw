# 01-用户系统

## 📋 功能概述

用户系统是 Excalidraw Plus 的核心基础，提供完整的用户生命周期管理，包括注册、登录、认证、个人资料管理等功能。

## 🎯 核心功能

### 1.1 用户注册
- **邮箱注册**: 支持邮箱验证注册
- **用户名唯一性**: 系统级用户名唯一性检查
- **密码安全**: 密码强度验证、bcrypt 加密存储
- **头像设置**: 支持上传自定义头像或使用默认头像

### 1.2 用户登录
- **多种登录方式**: 邮箱/用户名 + 密码
- **JWT 认证**: 无状态 Token 认证机制
- **会话管理**: Token 过期时间控制、刷新机制
- **登录状态保持**: 记住登录状态功能

### 1.3 个人资料管理
- **基础信息**: 用户名、邮箱、头像、个人简介
- **账户设置**: 密码修改、邮箱变更
- **偏好设置**: 主题、语言、通知偏好
- **账户安全**: 登录历史、设备管理

## 🔧 技术实现

### 1.4 数据模型
```typescript
interface User {
  id: string;
  email: string;
  username: string;
  password: string; // bcrypt 加密
  avatar?: string;
  bio?: string;
  preferences: {
    theme: 'light' | 'dark' | 'auto';
    language: string;
    notifications: boolean;
  };
  createdAt: Date;
  updatedAt: Date;
}

interface Session {
  id: string;
  userId: string;
  token: string;
  expiresAt: Date;
  deviceInfo?: string;
  ipAddress?: string;
  createdAt: Date;
}
```

### 1.5 API 端点
```typescript
// 认证相关
POST /api/auth/register     // 用户注册
POST /api/auth/login        // 用户登录
POST /api/auth/logout       // 用户登出
GET  /api/auth/me          // 获取当前用户信息
POST /api/auth/refresh     // 刷新 Token

// 用户管理
GET    /api/users/profile  // 获取个人资料
PUT    /api/users/profile  // 更新个人资料
POST   /api/users/avatar   // 上传头像
PUT    /api/users/password // 修改密码
GET    /api/users/sessions // 获取会话列表
DELETE /api/users/sessions/:id // 删除指定会话
```

## 📱 用户界面

### 1.6 注册页面
- **表单字段**: 邮箱、用户名、密码、确认密码
- **实时验证**: 字段格式验证、用户名可用性检查
- **视觉反馈**: 密码强度指示器、验证状态提示
- **引导流程**: 注册成功后自动跳转到工作空间选择

### 1.7 登录页面
- **登录表单**: 邮箱/用户名、密码输入
- **辅助功能**: 记住登录状态、忘记密码链接
- **错误处理**: 友好的错误提示信息
- **快速访问**: 支持键盘快捷键 (Enter 提交)

### 1.8 个人资料页面
- **头像区域**: 头像显示、上传、裁剪功能
- **基础信息**: 可编辑的用户名、邮箱、个人简介
- **设置选项**: 主题切换、语言选择、通知开关
- **安全设置**: 密码修改、会话管理

## ✅ 验收标准

### 1.9 功能验收
- [ ] 用户可以通过邮箱成功注册账户
- [ ] 用户名和邮箱唯一性验证正常工作
- [ ] 用户可以使用邮箱/用户名登录
- [ ] JWT Token 认证机制正常工作
- [ ] 用户可以上传和修改头像
- [ ] 用户可以修改个人信息和偏好设置
- [ ] 密码修改功能正常工作
- [ ] 会话管理功能正常工作

### 1.10 性能要求
- 注册流程完成时间 < 30秒
- 登录响应时间 < 2秒
- 头像上传处理时间 < 5秒
- API 响应时间 < 200ms

### 1.11 安全要求
- 密码必须 bcrypt 加密存储
- JWT Token 有效期不超过 24小时
- 支持 Token 刷新机制
- 敏感操作需要重新验证密码
- 防止暴力破解攻击
