# 03-文件管理

## 📋 功能概述

文件管理系统是 Excalidraw Plus 的核心组织功能，提供集合(Collections)系统、文件分类、标签管理、导入导出等功能，让用户能够高效地组织和管理绘图文件。

## 🎯 核心功能

### 3.1 集合系统 (Collections)
- **默认集合**: Private（私有）、Main（主集合）
- **自定义集合**: 用户可创建自定义集合
- **集合权限**: 私有、团队共享、公开访问
- **集合管理**: 重命名、删除、排序

### 3.2 文件组织
- **文件浏览器**: 左侧文件树导航
- **文件操作**: 创建、重命名、移动、删除、复制
- **文件搜索**: 全文搜索、标签筛选、类型过滤
- **文件排序**: 按名称、修改时间、创建时间排序

### 3.3 标签系统
- **标签创建**: 自定义标签名称和颜色
- **标签管理**: 编辑、删除、合并标签
- **多标签支持**: 单个文件可添加多个标签
- **标签筛选**: 基于标签的快速筛选

### 3.4 导入导出
- **导入格式**: .excalidraw、.json、图片文件
- **导出格式**: PNG、SVG、PDF、JSON
- **批量操作**: 批量导入、批量导出
- **版本控制**: 文件版本历史记录

## 🔧 技术实现

### 3.5 数据模型
```typescript
interface Collection {
  id: string;
  name: string;
  description?: string;
  workspaceId: string;
  ownerId: string;
  isDefault: boolean; // Private, Main 等默认集合
  visibility: 'private' | 'team' | 'public';
  color?: string;
  createdAt: Date;
  updatedAt: Date;
}

interface Drawing {
  id: string;
  title: string;
  description?: string;
  content: any; // Excalidraw JSON 数据
  collectionId: string;
  userId: string;
  thumbnail?: string;
  version: number;
  isPublic: boolean;
  createdAt: Date;
  updatedAt: Date;
  lastAccessedAt: Date;
}

interface Tag {
  id: string;
  name: string;
  color: string;
  workspaceId: string;
  createdBy: string;
  createdAt: Date;
}

interface DrawingTag {
  drawingId: string;
  tagId: string;
  createdAt: Date;
}
```

### 3.6 API 端点
```typescript
// 集合管理
GET    /api/collections                    // 获取集合列表
POST   /api/collections                    // 创建新集合
GET    /api/collections/:id               // 获取集合详情
PUT    /api/collections/:id               // 更新集合信息
DELETE /api/collections/:id               // 删除集合

// 文件管理
GET    /api/drawings                       // 获取绘图列表
POST   /api/drawings                       // 创建新绘图
GET    /api/drawings/:id                   // 获取绘图详情
PUT    /api/drawings/:id                   // 更新绘图
DELETE /api/drawings/:id                   // 删除绘图
POST   /api/drawings/:id/move              // 移动绘图到其他集合
POST   /api/drawings/:id/copy              // 复制绘图

// 标签管理
GET    /api/tags                           // 获取标签列表
POST   /api/tags                           // 创建新标签
PUT    /api/tags/:id                       // 更新标签
DELETE /api/tags/:id                       // 删除标签
POST   /api/drawings/:id/tags              // 为绘图添加标签
DELETE /api/drawings/:id/tags/:tagId       // 移除绘图标签

// 导入导出
POST   /api/import/excalidraw              // 导入 Excalidraw 文件
POST   /api/export/:id/png                 // 导出为 PNG
POST   /api/export/:id/svg                 // 导出为 SVG
POST   /api/export/:id/pdf                 // 导出为 PDF
POST   /api/export/batch                   // 批量导出
```

## 📱 用户界面

### 3.7 文件浏览器
- **侧边栏**: 左侧集合和文件树导航
- **集合列表**: 显示所有集合，支持拖拽排序
- **文件列表**: 显示当前集合下的所有文件
- **快速操作**: 右键菜单、拖拽移动、快捷键支持

### 3.8 文件网格视图
- **缩略图**: 文件预览缩略图
- **文件信息**: 文件名、修改时间、标签
- **操作按钮**: 编辑、分享、删除等操作
- **批量选择**: 支持多选和批量操作

### 3.9 搜索和筛选
- **搜索框**: 全局搜索功能
- **筛选器**: 按集合、标签、类型、时间筛选
- **排序选项**: 多种排序方式选择
- **高级搜索**: 支持复杂搜索条件
