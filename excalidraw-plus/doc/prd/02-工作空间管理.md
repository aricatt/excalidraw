# 02-工作空间管理

## 📋 功能概述

工作空间管理是 Excalidraw Plus 的核心组织功能，允许用户创建和管理多个独立的工作环境，每个工作空间都有独立的设置、成员和权限体系。

## 🎯 核心功能

### 2.1 工作空间创建与管理
- **创建工作空间**: 用户可以创建多个工作空间
- **工作空间切换**: 顶部下拉菜单快速切换
- **工作空间设置**: 名称、Logo、描述配置
- **工作空间删除**: 支持删除空工作空间

### 2.2 工作空间设置
- **基础信息**: 工作空间名称、Logo 上传
- **成员管理**: 邀请成员、设置角色权限
- **AI 偏好**: 启用/禁用 AI 功能
- **导入导出**: 工作空间数据备份与恢复

### 2.3 权限管理
- **角色系统**: Owner、Admin、Member、Viewer
- **权限控制**: 细粒度的功能权限控制
- **邀请管理**: 邀请链接生成、过期时间设置
- **成员审批**: 待审核邀请管理

## 🔧 技术实现

### 2.4 数据模型
```typescript
interface Workspace {
  id: string;
  name: string;
  description?: string;
  logo?: string;
  ownerId: string;
  settings: {
    aiEnabled: boolean;
    publicAccess: boolean;
    invitePolicy: 'open' | 'admin_only' | 'owner_only';
  };
  createdAt: Date;
  updatedAt: Date;
}

interface WorkspaceMember {
  id: string;
  workspaceId: string;
  userId: string;
  role: 'owner' | 'admin' | 'member' | 'viewer';
  joinedAt: Date;
  invitedBy?: string;
}

interface WorkspaceInvitation {
  id: string;
  workspaceId: string;
  email: string;
  role: 'admin' | 'member' | 'viewer';
  token: string;
  expiresAt: Date;
  invitedBy: string;
  status: 'pending' | 'accepted' | 'expired';
  createdAt: Date;
}
```

### 2.5 API 端点
```typescript
// 工作空间管理
GET    /api/workspaces              // 获取用户工作空间列表
POST   /api/workspaces              // 创建新工作空间
GET    /api/workspaces/:id          // 获取工作空间详情
PUT    /api/workspaces/:id          // 更新工作空间信息
DELETE /api/workspaces/:id          // 删除工作空间

// 成员管理
GET    /api/workspaces/:id/members  // 获取成员列表
POST   /api/workspaces/:id/invite   // 邀请新成员
PUT    /api/workspaces/:id/members/:userId // 更新成员角色
DELETE /api/workspaces/:id/members/:userId // 移除成员

// 邀请管理
GET    /api/workspaces/:id/invitations     // 获取邀请列表
POST   /api/workspaces/:id/invitations     // 创建邀请链接
DELETE /api/workspaces/:id/invitations/:id // 取消邀请
POST   /api/invitations/:token/accept      // 接受邀请
```

## 📱 用户界面

### 2.6 工作空间选择器
- **下拉菜单**: 顶部工作空间切换器
- **工作空间列表**: 显示用户所属的所有工作空间
- **创建按钮**: "+ Create workspace" 快速创建
- **角色标识**: 显示用户在每个工作空间的角色

### 2.7 工作空间设置页面
- **基础设置**: 工作空间名称、Logo 上传区域
- **成员管理**: 成员列表、角色管理、邀请功能
- **AI 偏好**: AI 功能开关、相关设置
- **高级设置**: 导入导出、危险操作区域

### 2.8 成员管理界面
- **成员列表**: 显示所有成员及其角色
- **邀请功能**: "Create invite link" 和 "Invite user" 按钮
- **待审核邀请**: "Pending invitations" 区域
- **权限控制**: 角色下拉选择、移除成员功能

### 2.10 权限验证
- Owner 可以执行所有操作
- Admin 可以管理成员和设置
- Member 可以创建和编辑内容
- Viewer 只能查看内容
- 非成员无法访问工作空间内容

### 2.11 性能要求
- 工作空间切换响应时间 < 1秒
- 成员列表加载时间 < 2秒
- 邀请发送响应时间 < 3秒
- Logo 上传处理时间 < 5秒
