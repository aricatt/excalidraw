## 🗄️ 数据库设计

### 8.4 核心数据模型
```sql
-- 用户系统
CREATE TABLE users (
  id TEXT PRIMARY KEY,
  email TEXT UNIQUE NOT NULL,
  username TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  avatar TEXT,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 工作空间
CREATE TABLE workspaces (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  logo TEXT,
  owner_id TEXT REFERENCES users(id),
  settings JSONB DEFAULT '{}',
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 绘图文件
CREATE TABLE drawings (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  description TEXT,
  content JSONB NOT NULL,      -- Excalidraw 数据
  collection_id TEXT,
  user_id TEXT REFERENCES users(id),
  workspace_id TEXT REFERENCES workspaces(id),
  version INTEGER DEFAULT 1,
  is_public BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 协作关系
CREATE TABLE collaborations (
  id TEXT PRIMARY KEY,
  drawing_id TEXT REFERENCES drawings(id),
  user_id TEXT REFERENCES users(id),
  permission TEXT NOT NULL,    -- 'read', 'write', 'admin'
  created_at TIMESTAMP DEFAULT NOW()
);
```

### 8.5 索引策略
```sql
-- 性能优化索引
CREATE INDEX idx_drawings_user_id ON drawings(user_id);
CREATE INDEX idx_drawings_workspace_id ON drawings(workspace_id);
CREATE INDEX idx_drawings_updated_at ON drawings(updated_at DESC);
CREATE INDEX idx_collaborations_drawing_id ON collaborations(drawing_id);
CREATE INDEX idx_collaborations_user_id ON collaborations(user_id);

-- JSONB 索引
CREATE INDEX idx_drawings_content ON drawings USING GIN (content);
CREATE INDEX idx_workspaces_settings ON workspaces USING GIN (settings);
```

## 🔌 API 设计

### 8.6 RESTful API 规范
```typescript
// API 版本控制
/api/v1/auth/*          // 认证相关
/api/v1/users/*         // 用户管理
/api/v1/workspaces/*    // 工作空间
/api/v1/drawings/*      // 绘图文件
/api/v1/collaborations/* // 协作功能

// HTTP 状态码规范
200 OK                  // 成功
201 Created            // 创建成功
204 No Content         // 删除成功
400 Bad Request        // 请求错误
401 Unauthorized       // 未认证
403 Forbidden          // 无权限
404 Not Found          // 资源不存在
409 Conflict           // 冲突
422 Unprocessable Entity // 验证失败
500 Internal Server Error // 服务器错误
```

### 8.8 认证和授权
```typescript

interface JWTPayload {
  userId: string;
```

### 8.9 数据安全
- **加密存储**: 密码使用 bcrypt 加密
- **传输加密**: HTTPS/WSS 强制加密
- **输入验证**: Zod schema 严格验证
- **SQL 注入防护**: Prisma ORM 参数化查询
- **XSS 防护**: 内容安全策略 (CSP)
- **CSRF 防护**: SameSite Cookie 设置
