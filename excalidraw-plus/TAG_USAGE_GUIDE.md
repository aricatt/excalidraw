# 标签功能使用指南

## 🎯 功能概述

标签系统允许你为绘图添加多个标签进行分类和筛选。与集合(Collection)不同,一个绘图可以同时拥有多个标签。

## 📋 快速开始

### 1. 给绘图添加标签

**步骤**:
1. 在 Dashboard 找到你想添加标签的绘图卡片
2. 在卡片底部右侧,找到三个小图标按钮
3. 点击**第一个图标**(标签图标,悬停时变绿色)
4. 在弹出的下拉菜单中,点击要添加的标签
5. 已添加的标签会显示 ✓ 勾选标记
6. 再次点击可以移除标签

**图标位置**:
```
┌─────────────────────────────┐
│  [绘图缩略图]                │
│                              │
├─────────────────────────────┤
│  绘图标题                    │
│  更新时间    [🏷️] [📁] [🗑️]  │
└─────────────────────────────┘
           标签 集合 删除
```

### 2. 通过标签筛选绘图

**步骤**:
1. 在左侧边栏找到 **TAGS** 部分
2. 点击任意标签名称
3. 主区域会只显示包含该标签的绘图
4. 点击 "All Drawings" 或其他集合可以清除标签筛选

**标签计数说明**:
- 标签名称后的数字 `(3)` 表示你有 3 个绘图使用了该标签
- 这个数字只计算**你自己的**绘图,不包括其他用户的

### 3. 创建新标签

**步骤**:
1. 在左侧边栏 **TAGS** 部分
2. 点击标题旁边的 **+** 按钮
3. 输入标签名称(最多50个字符)
4. 选择一个颜色(点击色块)
5. 点击 **Create** 按钮

**注意**: 标签名称必须唯一,不能重复

## 🔄 Collections vs Tags

### 什么时候用 Collection?

**集合(Collection)** 适合用于:
- 按项目组织绘图(如"2024年度报告"、"产品设计")
- 按工作流程分类(如"草稿"、"审核中"、"已完成")
- 需要明确归属的场景

**特点**:
- ✅ 每个绘图只能属于一个集合
- ✅ 类似文件夹的概念
- ✅ 有明确的所有权(属于某个workspace)

### 什么时候用 Tag?

**标签(Tag)** 适合用于:
- 交叉分类(如"重要"、"紧急"、"待审核")
- 按主题标记(如"UI设计"、"架构图"、"流程图")
- 需要多维度筛选的场景

**特点**:
- ✅ 每个绘图可以有多个标签
- ✅ 全局共享,所有用户都能看到
- ✅ 灵活的筛选和组合

### 组合使用示例

```
绘图: "登录页面设计 v2"
├─ Collection: "产品设计"
└─ Tags: ["UI设计", "重要", "待审核"]

绘图: "系统架构图"
├─ Collection: "技术文档"
└─ Tags: ["架构图", "重要"]
```

这样你可以:
- 通过集合查看所有"产品设计"
- 通过标签查看所有"重要"的绘图(跨集合)
- 通过标签查看所有"UI设计"(可能分布在不同集合中)

## 🐛 已知问题和解决方案

### 问题1: 点击标签后显示空列表

**原因**: 这个bug已经修复!之前是因为标签计数包含了其他用户的绘图。

**解决方案**: 
- 后端已更新,现在只计算你自己的绘图
- 如果标签显示 `(0)`,说明你确实没有绘图使用该标签

### 问题2: 选择标签后切换集合看不到绘图

**原因**: 这个bug已经修复!标签筛选和集合筛选会互相冲突。

**解决方案**:
- 现在选择集合时会自动清除标签筛选
- 选择标签时会自动清除集合筛选
- 两种筛选方式是互斥的

## 💡 使用技巧

1. **合理使用颜色**: 为不同类型的标签使用不同颜色,方便视觉识别
   - 🔴 红色: 紧急、重要
   - 🟢 绿色: 已完成、已审核
   - 🔵 蓝色: 进行中
   - 🟡 黄色: 待处理

2. **标签命名规范**: 使用简短、描述性的名称
   - ✅ 好: "UI设计"、"重要"、"待审核"
   - ❌ 差: "这是一个很重要的设计稿需要尽快审核"

3. **避免过度标签化**: 每个绘图建议不超过3-5个标签

4. **定期清理**: 删除不再使用的标签,保持标签列表整洁
